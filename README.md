## 📝 Project Overview

This capstone project was developed in partnership with Jarir Bookstore to address the challenge Small and Medium-sized Businesses (SMBs) face in implementing effective recommendation systems. Our objective was to research, build, and evaluate various models to find a practical and high-performing solution. The team's final model was implemented in a proof-of-concept website, demonstrating a clear path for potential integration into Jarir's e-commerce platform.

## 🛠️ My Role & Contributions

As a key member of the project team, I was responsible for foundational analysis and model benchmarking. My specific contributions included:

* Performing comprehensive Exploratory Data Analysis (EDA) using Matplotlib and Seaborn to uncover patterns in user-item interactions.

* Executing data cleaning and preprocessing pipelines to prepare the dataset for model training.

* Taking ownership of training and evaluating the LightFM model, a hybrid matrix factorization algorithm, to establish a performance baseline for the project.

* Calculating and analyzing key performance metrics, including Precision and Recall@10, to assess model effectiveness.

* Authoring the official introduction and objectives for the project's final poster, defining the core narrative for our presentation to stakeholders.

## 💻 Technical Stack

* Language: Python

## 🚀 Results & Achievements

* Contributed to a team effort that successfully developed a recommendation system achieving ~80% accuracy, demonstrating its viability for real-world application.
